# Zoha Aero Consulting — website + mini CMS

One-page website built to the brief of 15 October 2026 (Bespoke Consultants), with a small admin area.
Hosting: **Hostinger** (PHP 8.1 or newer).

## How it works

- Visitors get plain static pages (`index.html`, `privacy.html`): fast, no database.
- The owner edits text at **`/admin`**. "Save and publish" rebuilds the static pages immediately.
- Contact form messages are emailed **and** kept in the admin's *Messages* tab.

## Files

| Path | Purpose |
|---|---|
| `index.html`, `privacy.html` | Public pages — **generated by the CMS, do not edit by hand** |
| `contact.php` | Contact form handler: honeypot, time check, 5 messages/hour per visitor, email + saved copy |
| `admin/` | The admin screen (login, website text, privacy notice, messages, settings) |
| `cms/` | Private: settings (`config.php`), default text (`defaults.php`), page templates |
| `data/` | Private: saved content, admin password hash, messages. **Back this folder up.** |
| `assets/` | Stylesheet, self-hosted font, logo files, icons |
| `.htaccess`, `robots.txt`, `sitemap.xml`, `favicon.ico` | HTTPS redirect, security headers, caching, SEO basics |

## Deploy on Hostinger

1. **Before uploading**, copy `cms/config.example.php` to `cms/config.php` and change `SETUP_CODE` to your own secret (`config.php` is kept out of git).
2. hPanel → **Domains**: connect the domain. hPanel → **Security → SSL**: install the free SSL certificate.
3. hPanel → **Advanced → PHP Configuration**: choose PHP 8.2 or newer.
4. hPanel → **Emails**: create the business mailbox (e.g. `info@`) and a sending address (e.g. `website@`).
5. hPanel → **File Manager**: upload everything in this folder into `public_html/` (including the hidden `.htaccess` files).
6. Open `https://your-domain/admin`, enter the setup code and create the admin login (email + password).
7. In the admin, **Settings**: set the website address, the contact form email addresses → Save.
   **Website text → Contact**: set the email and phone → Save.
8. Send a test message through the contact form and confirm it arrives by email and in *Messages*.
9. Check that `https://your-domain/data/content.json` and `https://your-domain/cms/config.php` show "404 / Forbidden".

### Deploying from GitHub (hPanel → Advanced → Git)

- `index.html`, `privacy.html`, `robots.txt`, `sitemap.xml` are **not in git**: the CMS generates them on the server.
  After a deploy, the first visit runs `index.php`, which builds them. Owner edits are never overwritten by a deploy.
- `cms/config.php` and `data/` are **not in git** either. Create `cms/config.php` once in File Manager
  (copy of `cms/config.example.php` with your own `SETUP_CODE`); deploys leave it untouched.
- After changing the templates or styles in git, deploy, then click **Save and publish** once in the admin
  to rebuild the pages with the new templates.

## Security

- Login with email + password (password stored as a secure hash); 5 wrong logins → 15-minute lockout; logout after 2 hours of inactivity.
- All forms protected against cross-site request forgery; all text is escaped (no HTML can be injected).
- `cms/` and `data/` are blocked from the web. The admin is hidden from search engines.
- Forgot the login? Delete `data/admin.json` via File Manager and repeat step 6.
